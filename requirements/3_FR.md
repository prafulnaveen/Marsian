# Functional Requirements

This document contains the functional requirement for the to be solution


| FR# | Area of Application              | Funcational Requirement                                                                                                     | Comments |
| --- | -------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | -------- |
| 1   | Ticket System                    | Customer to be able to purchase the ticket online                                                                           |          |
| 2   | Ticket System                    | Ticket should have different category.  1. individual,  2. Family Pass                                                    |          |
| 3   | Ticket System                    | Validation of ticket purchased online at the entry point of the estate.                                                     |          |
| 4   | Popularity Tracking              | Monitor the Visitor traffic                                                                                                 |          |
| 5   | popularity Tracking              | Track engagement in different area of the park. Which Attraction are used more? which animal enclosures are most visited? |          |
| 6   | Animal Health Monitoring         | Key health metric of animals needs to be monitored. 1. General Health Status 2. Food and Water Consumption                  |          |
| 7   | Animal Population Monitoring     | Population for specific collection (eg jumping piranas) to be monitored                                                     |          |
| 8   | Ride/Attraction Safety Tracking | Monitoring the Safety and Maintenence of the ride are necessary.                                                            |          |
| 9   | Loyality Tracking                | Tracking the repeat visitors and incentivizing them.                                                                        |          |
| 10  | Edge Data Collection             | Need to MQTT capacble IOT devices through out the park to send the collected data to central system                         |          |
| 11  | Data ingestion and processing    | Ingested the data from the devices and other source and process them for the consumption by downstream layers.              |          |
| 12  | Reporting and Analytics          | Dashboard is required to visuaize the popularity data, animal health metrcis, to understand where improvement is required.  |          |
